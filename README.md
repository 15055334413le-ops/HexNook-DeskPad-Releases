# HN DeskPad 发布

HN DeskPad 是 Windows 上的启动台：按 **Alt + Space** 打开，集中显示全部应用、最近文件和常用文件夹。

## 下载安装（推荐）

[下载安装程序 HN-DeskPad-Setup.exe](https://raw.githubusercontent.com/15055334413le-ops/HexNook-DeskPad-Releases/main/HN-DeskPad-Setup.exe)

运行后选择安装位置即可，程序会自动在该位置创建「HN DeskPad」文件夹，并创建开始菜单快捷方式。无需管理员权限，可在「设置 → 应用」中卸载。

## 免安装版

最新版本：**0.1.1** — [DeskPad-0.1.1-win-x64.zip](https://raw.githubusercontent.com/15055334413le-ops/HexNook-DeskPad-Releases/main/releases/0.1.1/DeskPad-0.1.1-win-x64.zip)（[更新说明](releases/0.1.1/NOTES.md)）

历史版本见 [releases](releases) 目录；`latest.json` 记录最新版本信息，供安装程序与程序内更新读取。

## 说明

- 设置与缓存保存在 `%LOCALAPPDATA%\DeskPad`。
- 程序暂未进行代码签名，首次运行时 Windows SmartScreen 可能提示“已保护你的电脑”，点击“更多信息 → 仍要运行”即可。
- 系统要求：Windows 10 1809 及以上或 Windows 11，x64。
