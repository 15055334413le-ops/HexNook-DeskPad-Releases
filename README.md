# DeskPad 发布

DeskPad 是 Windows 上的启动台：按 **Alt + Space** 打开，集中显示全部应用、最近文件和常用文件夹。

## 下载

在右侧 [Releases](../../releases) 中下载最新版本的 `DeskPad-<版本>-win-x64.zip`。

## 安装与使用

1. 将压缩包解压到任意不会被清理的文件夹。
2. 双击 `DeskPad.exe` 启动，之后按 Alt + Space 打开或关闭启动台。
3. 请勿以管理员身份运行。

## 说明

- 设置与缓存保存在 `%LOCALAPPDATA%\DeskPad`，删除该文件夹即可完全清除。
- 程序暂未进行代码签名，首次运行时 Windows SmartScreen 可能提示“已保护你的电脑”，点击“更多信息 → 仍要运行”即可。
- 系统要求：Windows 10 1809 及以上或 Windows 11，x64。
