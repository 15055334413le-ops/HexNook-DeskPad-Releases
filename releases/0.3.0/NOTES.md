# HN DeskPad 0.3.0

## 新增
- **设置窗口重做**：左侧分区导航（通用 / 外观 / 应用 / 更新 / 关于），改了立即生效，不再需要「保存」。
- **两套主题**：扁平（默认）/ 毛玻璃（Windows 11 由系统合成器模糊背景，不额外占内存；Win10 自动退回扁平）。
- **启动台大小**：窗口 / 全屏。
- **图标样式**：原生图标 / 统一圆角底板。
- **应用管理**：默认隐藏 ODBC、注册表编辑器等系统工具（可开启显示）；右键「隐藏」，设置里可找回；可添加额外扫描的文件夹、手动添加应用，也可以把 exe / 快捷方式直接拖进启动台。
- **右键菜单**：打开、以管理员身份运行、打开文件位置、隐藏。
- **排序**：按名称 / 按使用频率。

## 修复
- 设置窗口「检查更新」完成后停在「正在检查…」不刷新。
