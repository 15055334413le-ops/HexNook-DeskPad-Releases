DeskPad 第一个版本。

## 功能
- Alt + Space 打开 / 关闭启动台（全屏游戏和演示时不呼出）
- 全部应用：搜索（支持拼音首字母）、键盘导航、启动
- 最近文件：图片、视频、演示文稿、PDF 显示内容缩略图；Word、Excel 等显示对应类型图标
- 常用文件夹
- 最近文件与常用文件夹均可切换图标 / 列表视图
- 托盘菜单、开机自启、设置窗口（托盘图标右键 →「设置…」）

## 安装
解压后双击 `DeskPad.exe`。请勿以管理员身份运行。程序暂未签名，SmartScreen 提示时点击“更多信息 → 仍要运行”。
