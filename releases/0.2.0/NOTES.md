# HN DeskPad 0.2.0

## 新增
- **内置在线更新**：打开启动台时每 24 小时自动查一次新版本（可在设置里关闭）。发现新版本时，搜索框右侧齿轮按钮右上角出现蓝点，托盘右键菜单多出「更新到 x.y.z」，设置窗口新增「更新」一行，可直接点「立即更新」。
- 更新检查放在一次性子进程里完成，主进程隐藏时依旧不联网、CPU 为 0。
- 安装程序新增静默更新模式：下载 → 校验 SHA-256 → 替换 → 重启，快捷方式与开机自启保持不变。发布包内附带 uninstall.exe。

## 升级说明
0.1.x 没有更新功能，这一版请重新运行 HN-DeskPad-Setup.exe 升级一次；此后即可在程序内一键更新。
